# 模板窗口与任务详情

本轮实现日期：2026-11-07。当前验证与加载记录见 [可靠性检查与验收](../testing/可靠性检查与验收.md)。

## 在电脑上管理任务模板

从运行中心“常用入口”右上角、托盘菜单或“任务记录”窗口点击 **任务模板**。

1. 选择模板所属的微信用户；只有一位用户时保持默认即可。
2. 点击“新建”，填写名称、输入要求、处理步骤、输出目录和输出格式。输出目录可填“工作目录”或其下的子目录，例如“工作目录/周报”。
3. 可选填写检查条件，每行一条；点击“规则示例”查看语法。
4. 点击“保存新模板”或按 `Ctrl+S`。之后在微信先说“开始对话”，再说“按周报模板运行”，或按已确认的附件批次执行模板。

选中已有模板可修改内容、复制或删除。名称为 1 至 40 个字，不能含空格；每位用户最多保存 30 个模板。已有模板保留名称，需要另一个名称时点击“复制模板”。离开未保存内容前会提示确认。

模板窗口需后台运行并启用任务记录，在线待机时也可编辑；保存只记录要求，不运行任务。微信端与桌面端使用同一份模板。微信端或另一窗口修改后，旧版本保存、删除会被拒绝，须重新读取。后台重启或任务库切换后也须重新读取。操作超时不自动重试，应先读取核对。

已经排队的任务保留入队时的模板版本、检查条件和固定输入，之后改模板或删模板不影响它。

## 将一次任务保存为模板

在“任务记录”中选中已结束的任务，点击 **保存为模板**：

- 原任务使用过模板：复制当时实际使用的定义，生成可编辑副本。
- 普通任务：以任务摘要和已记录的输入文件名生成草稿。普通任务结束后不保留可恢复的完整原始要求，因此需要补齐输入要求、输出格式并检查步骤后保存。

草稿不会自动保存或运行，也不会把模型回复当成原始任务要求。排队、执行中、等待确认或可恢复的任务暂不支持此操作。

## 更容易查看任务结果

选中任务后，上方显示摘要和执行、文字发送、人工结清状态；文件区域列出关联产物及记录时的核验说明，点击“打开文件位置”可定位仍存在的本机文件。

下方分为三个页签：

| 页签 | 内容 |
| --- | --- |
| 完整回复 | 任务库中仍保留的完整结果文字；无缓存时明确提示 |
| 输入与模板 | 任务编号、固定输入，以及本次采用的模板版本和要求 |
| 检查结果 | 配置的检查条件、检查结论和产物核验信息 |

操作按钮会显示“恢复这条任务”“取消排队”“标记已核对”“放弃恢复”或“归档记录”。暂不能执行时，旁边直接说明原因；待机时恢复任务会提示先在微信说“开始对话”。文字补发、产物取回等操作仍通过“复制微信指令”完成。
