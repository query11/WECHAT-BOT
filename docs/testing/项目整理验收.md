## 云端环境适配（2026-11-08）

首次 GitHub Actions 运行的 2086 项链路检查通过，但其他多组测试使用了托管 Windows 环境的 `C:\Users\RUNNER~1\...` 临时路径。路径解析会将其展开成完整用户名，触发既有的重定向拒绝规则；Git 钩子测试也因短名称与完整名称比较不一致而失败。

CI 现在将 `TEMP` 和 `TMP` 指向 GitHub 提供的完整 `runner.temp` 路径，使临时测试文件使用一致的规范路径。运行时的文件校验和所有测试断言保持原规则；普通配置也应使用完整 Windows 路径。修正后的云端结果以对应提交的 Actions 记录为准。

路径适配后，云端 2086 项链路检查、102 个快速测试和 521 个专项测试全部通过，无跳过项；该轮结束时仍因 Windows 默认终端编码无法打印中文汇总而返回非零。CI 因此显式设置 `PYTHONIOENCODING=utf-8`，用于完整保留中文输出并正常返回验证结果。
