```powershell
powershell -ExecutionPolicy Bypass -File toggle.ps1 -Status    # 只看开着没
powershell -ExecutionPolicy Bypass -File toggle.ps1 -Off       # 强制关
powershell -ExecutionPolicy Bypass -File toggle.ps1 -DebugLog  # 开，且 BRIDGE_DEBUG=1
```

## 使用速查.md：开关（原文）

## 开关

双击项目目录里的 **`微信开关.bat`**：没在跑就开，正在跑就关，就这一个动作。窗口里会打印结果：

- `[ ON ] bridge running, pid 12345` — 开了，那个最小化的 python 窗口别去关它（关了等于断开）
- `[OFF ] bridge stopped` — 关了
- `[FAIL] ...` — 没开起来，下面会跟上 `bridge.log` 的最后 8 行

不想双击也行：

```powershell
cd "C:\Projects\WECHAT-BOT"
powershell -ExecutionPolicy Bypass -File toggle.ps1 -Status    # 只看现在开着没
powershell -ExecutionPolicy Bypass -File toggle.ps1 -Off       # 强制关
powershell -ExecutionPolicy Bypass -File toggle.ps1 -DebugLog  # 开，且把日志开到最详细
```

没开机或没开开关时，本机不会处理消息；重新开启后会继续拉取微信服务端保留的消息。已接收任务的重启边界见文末。

平时**不用**开 `-DebugLog`。它会把每次空轮询都记一行，`bridge.log` 涨得很快，只在排查问题时开。

## 已知的局限

任务串行执行，一次一条。默认 10 分钟超时，超了中止。收件功能开启时，图片和文件会下载保存，关闭时才提示拿不到内容；反过来把本机的文件发到微信上是可以的（见上面那一节），但产物不会自动回传，得你说一句「发给我 <路径>」。进会认两种说法（自己打的短句、或整段转发的腾讯邀请文案），但光一条会议链接不认、光一串数字也不认，句子里带否定或推迟的也不接（这些都是刻意的，见那一节）。电脑关机链路就断——这是本机方案的固有代价，换云服务器能 7×24，但那样就碰不到你本机的文件了，而你要的恰恰是这个。现在它自己也能关机，所以「已安排关机」那条回话之后通常就没有下一条了：**锁屏和关机都回不来**——锁上之后只能你自己到电脑前解锁（远程解锁 2026-09-03 砍了），关机之后更是非人不可（远程开机要网卡和 BIOS 那一层的支持，没做）。

想加的话，下一步可以做：读懂你发来的图片和文件（现在只能看见有这么个东西）、以及多个 workdir 之间切换。开机自启没做，是有意的。
