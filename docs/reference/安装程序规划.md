# 安装程序规划

目标是一个 `WeChatAssistant-Setup-<版本>.exe`：用户双击就能装好，不需要事先安装 Python、Git 或 Node.js，也不需要管理员权限。装好后首次打开时，“使用引导”负责其余的配置。

本文记录已经为安装程序准备好的部分和打包方案。安装程序本身（Inno Setup 脚本和构建流程）还没有实现。

## 已就绪的部分

| 能力 | 位置 | 说明 |
| --- | --- | --- |
| 优先使用内置 Python | `desktop/python_runtime.ps1` | 程序目录有 `runtime\python\python.exe` 时，托盘、各窗口、开关和启动脚本都用它；否则用 `PATH` 中的 `python` |
| 首次使用引导 | `desktop/setup_wizard.ps1`、`app/onboarding.py` | 依次是免责声明、环境检查、安装依赖、选择目录、选择模型、扫码登录和微信绑定 |
| 安装 Claude Code | 引导第 2 步“一键安装” | 运行官方安装脚本 `irm https://claude.ai/install.ps1 \| iex`，装到 `%USERPROFILE%\.local\bin\claude.exe`，不需要 Node.js 或管理员权限；装好后会自动把这个路径写入 `claude_bin` |
| 卸载与停止 | `desktop/uninstall.ps1` | 关闭托盘、停止后台、移除自启动；加 `-RemoveData` 时同时删除个人数据，加 `-StopOnly` 时只关闭程序 |
| 应用内更新 | `app/updater.py` | `runtime\` 和个人数据不会被更新改动 |
| 许可与声明 | `LICENSE`、`DISCLAIMER.md` | 引导第一页要求勾选同意 |

## 安装位置

按当前用户安装到 `%LOCALAPPDATA%\Programs\WeChatAssistant`，Inno Setup 设置为 `PrivilegesRequired=lowest`。

不装到 `Program Files`：程序目录本身保存 `config.json`、`.runtime\` 等数据，应用内更新也会原地替换文件，而 `Program Files` 下的这些写入需要管理员权限。

## 内置 Python

1. 下载 python.org 的 Windows embeddable package（amd64，3.12.x），核对官方公布的校验值后，解压到 `runtime\python\`。
2. 修改 `runtime\python\python3XX._pth`：
   - 增加一行 `..\..\app`，即程序模块目录。嵌入版不会把脚本所在目录加入 `sys.path`，没有这一行时 `app\wechat_bridge.py` 找不到同目录模块。
   - 增加一行 `Lib\site-packages`。
   - 取消 `import site` 的注释，启用 `Lib\site-packages`。
3. 用 `get-pip.py` 装好 pip，再执行 `runtime\python\python.exe -m pip install -r requirements.txt`，把 `segno` 等依赖装进 `site-packages`。这样，引导里的“安装依赖”，以及更新后 `requirements.txt` 变化时的自动安装，都使用同一个解释器。

嵌入版没有 tkinter 和 venv，本项目都不使用。

## Claude Code

安装包不打包 Claude Code，原因有两个：它有自己的账号登录和自动更新，而且所有后端（包括 DeepSeek 等兼容接口）都通过它执行本机工具。

- 引导第 2 步会检测 Claude Code，没有时提供“一键安装”和“登录 Claude”。
- 公司网络无法访问安装地址时，用户可以按[官方安装说明](https://code.claude.com/docs/en/setup)手动安装，再在 `config.json` 的 `claude_bin` 中填写实际路径。

## 快捷方式与启动

- 开始菜单和桌面快捷方式名为“微信助手”，图标为 `wechat-assistant-v2.ico`。目标与自启动快捷方式相同：

  ```text
  powershell.exe -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File "{app}\desktop\launch_tray.ps1" -Show
  ```

- 安装完成页提供“启动微信助手”。首次启动时，`desktop\launch_tray.ps1` 发现引导未完成，会自动打开引导。
- 是否开机自启动在引导最后一页选择，安装程序不另外询问。

## 升级安装

- 新版安装包覆盖安装到同一目录，只替换程序文件。`config.json`、`BOT_MEMORY.md`、`.runtime\` 不在安装包里，保持不变。
- 替换文件前必须关闭程序，因为运行中的 `runtime\python\python.exe` 会被锁定：
  - 在 `[Code]` 的 `PrepareToInstall` 中运行 `desktop\uninstall.ps1 -StopOnly -Quiet`。
  - 再设置 `AppMutex=Local.WeChatAssistantTray` 兜底，托盘仍在运行时提示用户关闭。
- 应用内更新照常可用。安装包和应用内更新可以交替使用。

## 卸载

1. 卸载开始时询问“是否同时删除个人数据（配置、固定记忆、任务记录）？”，默认不删除。
2. `[UninstallRun]` 执行 `desktop\uninstall.ps1 -Quiet`。用户选择删除时，加上 `-RemoveData`。
3. 卸载程序删除它安装的文件，`[UninstallDelete]` 再清理 `runtime\` 和 `__pycache__\`。
4. 保留数据时，安装目录只剩个人数据。重新安装到同一位置会继续使用这些数据。
5. 用户在引导中选择的工作目录和收件目录始终不删除。

## 签名与 SmartScreen

未签名的安装包从网上下载后，Windows 会显示“Windows 已保护你的电脑”，用户需要点“更多信息 → 仍要运行”。要消除这个提示，需要代码签名证书或微软的云签名服务（有费用）。

在签名之前：

- 在下载说明中写清这一步，并在 Release 页面公布 SHA-256。
- 杀毒软件可能对“隐藏窗口的 PowerShell + 网络下载”产生误报。签名后误报通常会减少。
