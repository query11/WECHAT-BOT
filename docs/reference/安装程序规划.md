# Windows 安装程序：构建与维护

安装程序使用 Inno Setup，默认装入 `%LOCALAPPDATA%\Programs\WeChatAssistant`，固定 AppId 为 `{7B90F140-0A4A-4EC0-BE50-786F15A7C6A5}`。升级时不得更换此标识。安装器不请求管理员权限，开始菜单快捷方式为当前用户创建，桌面快捷方式可选。

## 本地构建

需要 Windows、Git、构建用 Python 和 Inno Setup。推荐 Inno Setup 7.0.2 及以上（自带官方简体中文翻译）；6.x 在编译时提示警告并回退英文。CI 要求官方简体中文文件存在。

先提交待发布代码；构建只打包指定 Git 提交，未提交文件不会进入安装包：

```powershell
powershell -ExecutionPolicy Bypass -File installer\build.ps1
# 可选：指定已有标签和编译器
powershell -ExecutionPolicy Bypass -File installer\build.ps1 -Ref v1.0.0 -ISCC "C:\Program Files (x86)\Inno Setup 7\ISCC.exe"
powershell -ExecutionPolicy Bypass -File installer\smoke.ps1
```

输出在 `dist/WeChatAssistant-Setup-<VERSION>.exe`，构建来源记录在 `dist/build-info.json`。`runtime/`、`dist/` 和 `.runtime/` 不提交到 Git。测试会真实创建／移除当前用户快捷方式和卸载注册项，应在独立 Windows 环境运行，不应对已有正式安装运行 smoke 脚本。

## 固定的 Python 来源

- 版本：CPython **3.12.10**，Windows embeddable amd64。
- 官方下载：[python-3.12.10-embed-amd64.zip](https://www.python.org/ftp/python/3.12.10/python-3.12.10-embed-amd64.zip)
- 官方摘要来源：[Sigstore bundle](https://www.python.org/ftp/python/3.12.10/python-3.12.10-embed-amd64.zip.sigstore)。下载内容摘要与 `messageSignature.messageDigest` 和透明日志记录中的 SHA-256 一致。
- CI 取值记录：[Windows provenance run](https://github.com/query11/WECHAT-BOT/actions/runs/42485471470)，`python-release-provenance` artifact。
- 固定 SHA-256：`4acbed6dd1c744b0376e3b1cf57ce906f9dc9e95e68824584c8099a63025a3c3`。

每次构建在解压前检查这一固定摘要，失败立即停止。`tools/python_release_probe.py` 可重新下载并核对官方摘要；更换 Python 版本必须重新核验并修改脚本中的固定值。该比较是官方 HTTPS 下载的摘要核对，并非完整 Sigstore 证书链验证。

嵌入式 Python 位于 `runtime/python/`，`python312._pth` 加入 `Lib\site-packages` 与 `..\..\app`，使平级模块导入正常。构建机只安装纯 Python wheel（pip 固定为 25.0.1，业务依赖来自 `requirements.txt`）。包内保留 Python 自带许可证。构建会实际导入 segno、pip、sqlite3、ctypes，并运行 onboarding status。

## 生命周期与数据保护

安装载荷由 `git archive` 产生，包含程序和示例，不包含配置、记忆、日志、任务数据库或密钥。升级调用旧安装的 `uninstall.ps1 -StopOnly -Quiet`，必须停止成功才能覆盖。后台匹配绝对路径，避免误停其他安装。

交互卸载询问是否删除个人数据，默认保留；静默卸载保留。删除数据只清理已知本机数据，不递归删除整个安装目录。工作和收件目录始终保留；与程序／数据目录重叠或出现 junction/symlink 时拒绝清理。无论是否保留数据，清理程序子目录及更新时新增的程序文件，未知用户文件保留。

CI 的 `installer/smoke.ps1` 在含空格和中文的临时路径实际安装，验证内置 Python、引导、WinForms、自启动路径、开始菜单与桌面快捷方式、运行中覆盖升级、配置／记忆／任务历史保留、静默卸载、重新安装、显式删除数据和二次卸载。另起一份模拟后台检查安装隔离。卸载的“删除数据”分支调用与交互确认共用的 helper；CI 不模拟点击确认框。

## Release

分支推送和 PR 只构建与测试。推送与 `VERSION` 一致的 `vX.Y.Z` 标签后，Windows 验证、ZIP 和 EXE 构建全部成功才发布。资产为源码 ZIP、安装 EXE 和两行 `SHA256SUMS.txt`，详见[发布与更新](发布与更新.md)。安装包未签名，因此可能出现 SmartScreen 提示。
